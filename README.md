# Datavakwerk (datavakwerk.nl) — zzp business & data analist voor de publieke sector

Website voor een freelance business/data/informatie-analist, gebouwd met React + Vite.
Versie 2 van `business-analyse`: zelfde opzet en blauwe huisstijl,
maar toegespitst op stuurinformatie, procesanalyse en businesscases bij de
(rijks)overheid.

## Ontwikkelen

```bash
npm install
npm run dev      # ontwikkelserver
npm run build    # productiebuild in dist/
npm run preview  # bekijk de productiebuild
```
